Solar System Explorer

3054 Web Programming - Project 2

Topic Description

The solar system is a collection of planets, their moons, and other objects that orbit the Sun. Even though there is widespread interest in space, we still only know very little about what seems like an endless nothing. Some planets are rocky while others are gassy, what makes moons different from planets, and what makes dwarf planets different from regular planets. This will do its best to address those questions by building a web application that will let the users explore the solar system through specific paths. With this application, I will aim to create an easily browsable tool that lets the user select a category with specific information and be shown accurate information and images.

NASA’s Solar System Exploration website is the most detailed and professional but is built more as a reference or a quick search tool, not a guided web application. Their website assumes the user already knows what they are looking for, rather than teaching them what they don’t already know. Many other sites similar to this like to oversimplify their websites and don't let the user learn as much because most of the focus is on the aesthetics.

Application Description

Home Page

The landing page will introduce the Solar System Explorer for new users. It will feature a title banner with a brief welcoming message with more explaining the purpose of the site and an image of the solar system to help the user visualize what they will be learning about.

Exploration Page

This is the page that will implement the double step sequence. The first is where the user will select between 4 planetary categories: Inner Planets, Outer Planets, Dwarf Planets, and Moons. The first choice will determine the second step options and the second step options will give the user different outputs. For example, the Inner Planets would be Mercury, Venus, Earth, and Mars, but if you selected Moons, you would see Earth’s Moon, Titan, Io, and Europa. Every one of the 16 total choices will have a similar looking information display but with the proper information for your selections.

  1. Inner Planets
    1. Mercury
    2. Venus
    3. Earth
    4. Mars
  2. Outer Planets
    1. Jupiter
    2. Saturn
    3. Uranus
    4. Neptune
  3. Dwarf Planets
    1. Ceres
    2. Pluto
    3. Haumea
    4. Eris
  4. Moons
    1. Earth's Moon
    2. Titan
    3. Io
    4. Europa

Data Page

This page will focus on additional information about the solar system that wasn’t shown on the Exploration Page. This will include some brief history, as long as the discovery and exploration of these. The telescopic images are great in this section.

Contact Us Page

The last page will just be a static contact form. It will collect the name, email address, and a text message field, allowing the user to submit questions or feedback they may have about anything regarding the website.
